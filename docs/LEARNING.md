# 코드를 이해하고 설명하기

완성된 파일을 실행한 다음, 아래 질문을 자신의 말로 설명하고 직접 코드를 바꿔 보세요.

## 프로그램 흐름

`main.py`에서 `QuizGame` 객체를 만듭니다. 생성 시 `state.json`을 읽고 메뉴를 반복합니다.
메뉴 1은 문제를 순서대로 표시하고, 답을 검증한 뒤 정답 수를 계산합니다.
완료된 회차만 최고 기록과 비교하여 저장합니다.

## 두 클래스의 역할

| 항목 | Quiz | QuizGame |
|---|---|---|
| 책임 | 한 문제 표현과 정답 판정 | 전체 게임 진행과 저장 |
| 속성 | question, choices, answer | quizzes, best_score, best_correct, best_total |
| 메서드 예 | display, is_correct, to_dict | run, play, add_quiz, load_state, save_state |

클래스는 객체를 만드는 설계도입니다. `Quiz(...)`를 호출하면 개별 문제 객체가 생깁니다.
`__init__`은 생성 시 초기 값을 설정합니다. `self`는 현재 객체를 가리킵니다.
`self.answer`는 속성이고, `self.is_correct(...)`는 메서드 호출입니다.

## Python 기본 문법 찾기

| 개념 | 이 프로그램에서의 예 |
|---|---|
| 변수 | `correct`에 맞힌 개수를 보관 |
| int | 정답 번호 1~4, 맞힌 문제 수 |
| str | 문제와 선택지 문장 |
| bool | `is_correct()`의 True/False, 저장 가능 여부 |
| list | 여러 Quiz 객체를 담는 `self.quizzes` |
| dict | 저장할 필드 이름과 값을 연결하는 `data` |
| None | 아직 완료한 회차가 없다는 상태 |
| if/elif/else | 메뉴 번호에 따른 기능 선택 |
| for | 선택지와 모든 퀴즈 순회 |
| while | 유효한 입력을 받을 때까지 반복, 종료 전까지 메뉴 반복 |
| 매개변수 | `read_int(prompt, minimum, maximum)`에 필요한 값 전달 |
| 반환값 | 입력 함수가 검증한 정수를 `return`으로 전달 |
| try/except | 숫자 변환·파일 처리·입력 중단 오류 처리 |

## JSON과 파일 입출력

JSON은 이름과 값, 목록을 텍스트로 표현하는 형식입니다.
Python 객체 자체를 저장하지 않고 `to_dict()`로 저장 가능한 형태로 바꿉니다.
`json.dump()`는 파일에 쓰고 `json.load()`는 파일에서 읽습니다.
`with`는 파일을 사용한 뒤 닫습니다. UTF-8은 한글을 일관되게 처리합니다.
불러온 데이터는 자료형·선택지 수·정답 범위를 검사한 후 실제 상태에 적용합니다.

## Git 명령어 설명

| 명령 | 역할 |
|---|---|
| init | 현재 폴더를 Git 저장소로 초기화 |
| add | 다음 커밋에 담을 변경 선택 |
| commit | 변경 내용을 메시지와 함께 이력으로 기록 |
| push | 로컬 커밋을 원격 저장소로 전송 |
| pull | 원격 변경을 받아 현재 브랜치에 통합 |
| checkout | 브랜치 전환. `-b` 옵션은 생성하면서 전환 |
| clone | 원격 저장소와 이력을 새 폴더에 복제 |
| merge | 다른 브랜치의 변경을 현재 브랜치에 병합 |

커밋은 한 기능의 변경을 설명할 수 있는 단위로 남깁니다.
이 프로젝트의 초기 단계 커밋에는 아직 뒤 단계 메서드가 없는 개발 중 상태가 포함됩니다.
실행·검증은 최종 main 브랜치에서 진행하세요.

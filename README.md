# 두피·모발 퀴즈 게임

## 프로젝트 개요

Python 콘솔에서 두피·모발 기초 지식 퀴즈를 풀고, 직접 문제를 등록하는 프로그램입니다.
표준 라이브러리만 사용하며 퀴즈와 최고 점수를 JSON으로 저장합니다.

## 퀴즈 주제와 선정 이유

두발·두피·모발에 대한 관심을 프로그래밍 학습과 연결하기 위해 선택했습니다.
케라틴, 큐티클, 모낭, 멜라닌, 피지, 성장기, 모간, 두피에 관한 4지선다형 8문제를 제공합니다.
기본 문제는 해부학과 구조에 대한 기초 지식을 다룹니다.

## 실행 방법

Python 3.10 이상과 Git을 설치합니다. 추가 패키지는 설치하지 않습니다.
VS Code에서 이 README가 들어 있는 `scalp_hair_quiz` 폴더를 열고,
상단 **터미널 → 새 터미널**을 선택합니다. PowerShell을 사용해도 됩니다.

```powershell
python --version
git --version
python main.py
```

`python` 명령이 동작하지 않고 `py`가 설치되어 있다면 `py main.py`로 실행합니다.
Windows에서 한글 인코딩 문제가 있다면 `python -X utf8 main.py`를 사용합니다.
이 작업 환경에서는 Python 3.14.7, Git 2.55.0으로 검증했습니다.
Python 실행 별칭이 동작하지 않을 경우 실제 설치된 Python 경로를 사용해야 합니다.

## 기능 목록

| 메뉴 | 기능 |
|---|---|
| 1 | 모든 퀴즈 출제, 정답·오답 안내, 결과 계산 |
| 2 | 문제·선택지 4개·정답 번호를 입력해 새 퀴즈 등록 |
| 3 | 등록된 문제 목록 확인 |
| 4 | 최고 점수와 해당 회차의 정답 수 확인 |
| 5 | 현재 데이터를 저장하고 종료 |

입력 공백, 빈 입력, 숫자가 아닌 입력, 범위 밖 번호를 검사합니다.
Ctrl+C와 EOF가 발생하면 완료된 내용을 저장하고 종료합니다.
등록 중인 미완성 문제와 풀이 중인 회차의 점수는 저장하지 않습니다.
파일이 없으면 기본 퀴즈를 사용합니다. 손상된 파일은 백업 후 기본 데이터로 복구합니다.
읽기 오류 또는 백업 실패 시 원본을 보호하기 위해 저장을 중지합니다.
쓰기 실패 시 안내하며, 저장 성공으로 표시하지 않습니다.

## 데이터 파일 설명

`state.json`은 현재 터미널 위치와 관계없이 `main.py`가 있는 프로젝트 루트에 생성됩니다.
UTF-8 인코딩과 읽기 쉬운 들여쓰기를 사용합니다.

```json
{
  "quizzes": [
    {
      "question": "모발을 구성하는 대표적인 단백질은?",
      "choices": ["헤모글로빈", "케라틴", "인슐린", "알부민"],
      "answer": 2
    }
  ],
  "best_score": 100.0,
  "best_correct": 1,
  "best_total": 1
}
```

| 필드 | 의미 |
|---|---|
| quizzes | Quiz 객체를 딕셔너리로 변환한 문제 목록 |
| question | 비어 있지 않은 문제 문자열 |
| choices | 비어 있지 않은 문자열 4개 |
| answer | 1~4의 정답 번호 |
| best_score | 최고 백분율 점수. 아직 완료한 게임이 없으면 null |
| best_correct | 최고 점수를 얻은 회차의 정답 수 |
| best_total | 최고 점수를 얻은 회차의 전체 문제 수 |

점수는 `정답 수 / 문제 수 × 100`이며 소수 둘째 자리까지 반올림합니다.
문제 수가 바뀌어도 백분율로 비교하며, 동점이면 기존 기록을 유지합니다.
0점으로 완료한 회차와 아직 플레이하지 않은 상태를 구분합니다.
임시 파일 `state.json.tmp`에 쓴 뒤 교체하여 저장 도중 원본 손상 위험을 줄입니다.
손상 파일은 `state.corrupt.날짜시간.json`으로 보관합니다.
개인 데이터는 `.gitignore`에 포함되어 GitHub에 올라가지 않으며 첫 실행 때 생성됩니다.
동시에 여러 프로그램을 실행하여 같은 파일을 수정하는 사용 방식은 지원하지 않습니다.

## 검증 방법

```powershell
python -m unittest -v
git log --oneline --graph --all
```

자동 검증 15개로 재실행 유지, 잘못된 입력, 정답·오답, 최고 점수, 빈 목록,
손상 파일·잘못된 스키마·잘못된 UTF-8, 파일 읽기·쓰기 실패, Ctrl+C·EOF를 확인합니다.
테스트 데이터는 임시 폴더에 분리하며, 실제 콘솔 검증에서 기존 데이터가 있으면 복원합니다.
